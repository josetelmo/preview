# José Telmo — Preview

Site pessoal e portfólio de **José Telmo**, professor e profissional de marketing com atuação em **Inteligência Artificial, estratégia digital, design, comunicação e educação**.

🌐 **Site:** https://josetelmo.github.io/preview/

## Objetivo

Este repositório hospeda uma página estática publicada com GitHub Pages. O projeto foi estruturado para apresentar perfil profissional, áreas de atuação, conteúdos e canais oficiais, com atenção a:

- SEO técnico e semântico
- GEO (Generative Engine Optimization)
- dados estruturados com Schema.org
- acessibilidade e HTML semântico
- compartilhamento em redes sociais
- rastreamento e indexação por mecanismos de busca
- contexto legível por sistemas de IA

## Tecnologias

- HTML5
- Tailwind CSS via CDN
- Lucide Icons
- Google Fonts
- GitHub Pages

## SEO e GEO

A página inclui:

- `<title>` e meta description descritivos
- URL canônica
- diretivas `robots`
- Open Graph
- Twitter Cards
- JSON-LD com `Person`, `ProfilePage` e `WebSite`
- `sitemap.xml`
- `robots.txt`
- `llms.txt` com contexto factual sobre o perfil e o conteúdo do site

> O arquivo `llms.txt` é um recurso complementar para fornecer contexto legível por sistemas de IA. Ele não substitui sitemap, dados estruturados ou boas práticas tradicionais de SEO e não deve ser tratado como garantia de indexação.
